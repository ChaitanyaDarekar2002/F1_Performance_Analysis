# 🎯 Project Objective

The main objective of this project is to analyze Formula 1 historical racing data and transform it into meaningful and interactive visual insights using Power BI.

The dashboard provides a comprehensive view of:

Drivers
Constructors
Race performance
Grand Prix winners
Circuits
Race evolution
Decade-wise trends
Continental distribution

This project demonstrates practical skills in Data Analytics, Power BI, Power Query, DAX, Data Modeling, Data Visualization, and Business Intelligence.
